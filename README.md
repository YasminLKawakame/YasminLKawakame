## 🌷 Sobre mim

Olá! Sou a Yasmin, estudante de programação e tecnologia, apaixonada por
aprender coisas novas e transformar ideias em projetos.

Atualmente, estou desenvolvendo minhas habilidades em programação,
explorando principalmente o desenvolvimento backend, lógica de
programação e criação de APIs.

Acredito que cada projeto é uma oportunidade de aprender algo novo. Este
espaço reúne minha evolução, meus estudos e tudo o que venho construindo
ao longo dessa jornada.

## 🌸 Projetos em destaque

### 🌷 [API - Laboratório de Ensaios](https://github.com/YasminLKawakame/API-Laboratorio-de-Ensaios)

API REST para gerenciamento de informações de um laboratório industrial.

- Gerenciamento de ensaios, equipamentos e analistas.
- Operações CRUD e atualização parcial.
- Integração com banco de dados MySQL.
- Organização em camadas: Model, Repository, Controller e Routes.

**Tecnologias:** JavaScript · Node.js · Express · MySQL · Postman

### 🌱 [Primeira Rota - Backend](https://github.com/YasminLKawakame/Primeira-Rota-Backend)

Projeto de API REST para gerenciamento de produtos, categorias e fornecedores.

- Cadastro, listagem, consulta, atualização e exclusão.
- Organização de rotas e recursos.
- Testes de requisições HTTP.

**Tecnologias:** JavaScript · Node.js · Express · Postman

### 📚 [Lógica de Programação](https://github.com/YasminLKawakame/Logica-Programacao)

Repositório de estudos com atividades, exercícios, desafios e pequenos jogos desenvolvidos durante as aulas de lógica de programação.

**Conteúdos:** JavaScript · Node.js · Algoritmos · Estruturas condicionais · Laços de repetição · Arrays · Funções
