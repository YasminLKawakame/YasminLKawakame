## 🌸 Featured Projects

### 🌷 [API - Laboratório de Ensaios](https://github.com/YasminLKawakame/API-Laboratorio-de-Ensaios)

Desenvolvimento de uma API REST para gerenciamento de informações de um
laboratório industrial.

-   Gerenciamento de ensaios, equipamentos e analistas.
-   Operações CRUD e atualização parcial.
-   Integração com banco de dados MySQL.
-   Arquitetura organizada em camadas.

**Stack:** JavaScript · Node.js · Express · MySQL · Postman

### 🎀 [SafeStock - Controle de EPIs](https://github.com/YasminLKawakame/SafeStock-Controle-EPIs)

Sistema para gerenciamento de Equipamentos de Proteção Individual (EPIs)
e funcionários.

-   Cadastro e gerenciamento de EPIs.
-   Controle de funcionários e seus status.
-   Arquitetura Model, Repository e Controller.
-   Aplicação de conceitos de orientação a objetos.

**Stack:** JavaScript · Node.js

### 🌸 [ProdControl - Controle de Produção](https://github.com/YasminLKawakame/ProdControl-Controle-Basico-de-Producao)

Sistema de gerenciamento básico de produção industrial.

-   Gerenciamento de máquinas e operadores.
-   Controle de ordens de produção.
-   Operações CRUD.
-   Organização em camadas e separação de responsabilidades.

**Stack:** JavaScript · Node.js

### 🌱 [Primeira Rota - Backend](https://github.com/YasminLKawakame/Primeira-Rota-Backend)

Projeto de desenvolvimento de uma API REST para gerenciamento de
produtos, categorias e fornecedores.

**Stack:** JavaScript · Node.js · Express · Postman

### 📚 [Lógica de Programação](https://github.com/YasminLKawakame/Logica-Programacao)

desenvolvidos durante o aprendizado de programação.
